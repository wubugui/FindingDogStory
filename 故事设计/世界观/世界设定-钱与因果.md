# 世界设定 · 钱与因果

> 制作人 2026-09-01 口述定稿，本文档为首次记录。
> 与 `supernatural-lore.md`（超自然底层设定）平行，专管「钱」这一条。
> 本文档同时覆盖**世界设定**与**玩法机制**——这条设定的要点就是两者不可分。

---

## 一、一句话

**这个世界里钱是最硬的通货，硬在阴阳两界通用。**

不光人爱钱。鬼爱钱、阴差爱钱、开了灵智的妖也爱钱。所以钱不是单纯的经济资源，
它是**跨界的交易媒介**，也是这个世界处理因果的通用手段。

野外遇野鬼拦路，最省的脱身办法是撒一把铜钱。遇妖可以拿钱贿赂（不一定奏效）。
遇阴差同样是拿钱打点。

## 二、这条设定的根

它不是新的，是总纲里已有的一句话的展开：

> **工钱一文不少收——收钱是断因果，不是爱财。**
> ——`Demo制作资料/游戏总纲_设定剧情玩法.md` §7（李天狗·行止与年纪）

**钱货两清即因果两清。** 这是全部的底层逻辑。由它可以推出：

- **付钱 = 断因果。** 事办了，钱付了，两不相欠，这条线到此为止。
- **收钱 = 断因果。** 李天狗替人办事必收工钱，不是爱财，是不肯欠、也不肯让人欠。
- **撒钱脱身 = 花钱买断一条正在成形的因果。**
- **贿赂阴差／妖 = 同理**，只是对方未必肯做这桩生意。

由此得到危险面：

> **收了不该收的钱，不是断因果，是接上了别人的因果。**

不是"这钱脏"，是**这笔钱本来是给别人的、或本来要送到某处去，你把它收了，
那桩没结的事就转到你头上。**

以及——这一条同样重要——

> **不收，这桩事就没了断，悬着。**

活干了钱不收，账没清，线还连着你。**李天狗从不拒收**，"一文不少收"不是爱财，
是他知道拒收比收下更麻烦。

## 三、两种钱

| | 阳钱 | 那种钱 |
|---|---|---|
| 是什么 | 市面流通的铜钱、银两、铜元 | 外观像铜钱，成色不对，不识货的人会当成私铸假钱 |
| 用途 | 买东西；打发一般的野鬼、小祟 | **特殊贿赂与特殊交易**的唯一硬通货 |
| 谁收 | 人，也能对付低阶的东西 | 阴差、有位格的东西、够分量的交易对象 |
| 怎么得 | 干活、支线、捡漏 | 见下 |

**那种钱的获取方式：**

1. **用极大量的阳钱去换。** 汇率极不对等——它贵，而且贵得没道理。
2. **能跟你换的对象是概率出现的，没有规律。** 撞得上就撞上，撞不上没辙。
   （与 `supernatural-lore.md` §4.3「不可掌控」一致：这类互动本就带随机性。）
3. **最普遍的搜集手段是主动触犯禁忌。**
   ——本设定最关键的一条：**玩家想要那种钱，就得去惹事。**
   规矩本教你怎么活命；想变强，你得挑着规矩去犯。

# 玩法机制

## 四、核心回路：每一次收钱都是一次赌

序章之后玩家学到第一条规矩：**有的钱不能收。**

学会之后，游戏里**每一次收钱都从"领奖励"变成"做判断"**。
**设计目标：玩家每一次面对这个选择都要想很久。这就是玩法本身，不是玩法的装饰。**

要让它真的难，两个条件缺一不可：

### 4.1 两边都要付代价（关键）

**如果拒收是免费的，最优解永远是"拿不准就别收"，玩家三分钟学会，玩法当场死掉。**

所以：

- **收** → 可能接上别人的因果
- **不收** → 这桩事悬在你身上不了断

**两边都是接因果，只是接的东西不一样。没有安全默认值。** 这才是想很久的理由。

### 4.2 其实是三选，不是两选

| 选项 | 需要什么 | 对应既有设定 | 结果 |
|---|---|---|---|
| **收下，硬扛** | 只要胆子，**象**都不用认全 | **制煞**（旁门） | 见效快、不稳定、反噬更狠 |
| **不收，躲开** | 认得出不对（**象**） | —— | 悬着、拖延、不解决 |
| **送走／还回去** | 三层齐：知道是啥、为啥、送哪儿（**象理术**） | **化煞**（正道） | 慢、要真懂、一劳永逸 |

化煞 vs 制煞的底层逻辑见 `supernatural-lore.md` §4.1.1，不用新造。

**关二狗天生是干制煞的那种人。** 他是个假道士，"收下硬扛"就是他的默认动作。
玩家一开始只会这一招；象理术攒起来，才逐渐买得起"送走"这个选项。
**能力成长 = 可选项变多，不是数值变大。**

### 4.3 判断工具就是象理术

> 先认得是啥（**象**）、再懂得为啥（**理**）、末了才晓得咋办（**术**）。
> 三层齐的收得了，三层缺一的只能查、只能化一点是一点、只能跑。
> ——`游戏总纲` §7 / §12

**注意动词就是「收」。** 玩家给一枚钱补齐象理术三层的过程，
和李天狗判断一桩活能不能接，是同一个动作、同一门手艺。

随着象理术积累，玩家逐渐：
- 判得更准——**但永远不是确知**（见 §5.2）
- 解锁更多"敢收"和"送得走"的机会

### 4.4 提示系统：随机，而且必须互相打架

象理术给出的是**随机提示**（细则待专门设计）。定死的原则只有一条：

> **提示必须互相矛盾。一条说能收、一条说不能收，而且两条都可能是真的。**

这样"想很久"是在**权衡证据**，不是在等信息刷出来。
（`supernatural-lore.md` §4.3「不可理解：任何解释性文本都会随时间扭曲」已经许可这一点。）

## 五、后果的分层

### 5.1 严重度分层

这不是与既有设定的冲突，是分层——`supernatural-lore.md` §4.4 因果链写的
「违反禁忌不一定立刻遭殃，可能数日数月后以间接方式显现」是**下层**：

| 接上的因果 | 后果节奏 |
|---|---|
| 小因果（低阶的东西、无主的零碎） | 延迟、间接、数日至数月后显现 |
| 有位格的东西的因果 | **即时、致命**；或直接丢失大量钱财 |

细则待设计。原则：**玩家必须能从后果的形态倒推出自己接上了什么级别的东西。**

### 5.2 能不能"知道"

`supernatural-lore.md` §4.3 三不原则之「不可理解：玩家永远无法获得完整真相」仍然成立。

象理术的积累必须表述为**「概率判断越来越准」，绝不能写成「最后能确知」**。
**象理术给的是行价，不是答案。**

## 六、剧情锚点（序章·已有内容）

这条设定不是空降的，序章现有内容里已经有它的落脚点：

1. **官爷那包工钱里混着一枚"私铸的"。**
   > 「……龟儿这个是私铸的嘛？」「……算了算了，算你一个。」

   关二狗一眼看走：看见毛边就当假钱，收下、嫌弃、又懒得计较。
   **私铸是他的判断，不是这枚钱的身份。**

2. **赌坊门外，他捡了地上散落的铜钱。**
   > 蹲着蹲着看见地上散落几枚铜钱。他哦豁了一声，一枚一枚捡起来，嘿嘿笑：一文是一文嘛。
   > ——`故事设计/关二狗的故事.md` §六

   按本设定，**这一拍已经是「有的钱不能收」的第一次犯规**，而且写在定稿故事里。
   **规矩的来处就在这儿：他学会这条规矩，是因为他已经犯过了。** 不用另外设计教学关。

   ⚠ 与游戏数据有出入：故事稿是「几枚」，`赌坊输钱` 过场是只剩一文。需对齐。

3. **癞子摸得出这枚钱。**
   全镇唯一一上手就认出「边边上毛起的」的人，整天蹲在地上捡钱，前天还捡到过一个。
   ——他可能一直在捡不该捡的钱。（未定，留口子）

## 七、序章那一枚的身份（已定）

- 它与**牛头凼那具实体不可分割**。
- **它是欠鬼的钱，没送到。**
- 所以**老有鬼出现在这钱旁边**。它掉在地上滚走，是看不见的小鬼拿它玩、没抓稳。
- **鬼收得到，拿不走**——买路钱、口含钱都必须由**活人**送到。
  所以：赌坊不收它，他甩不掉它，它只能被人送到该去的地方。
- **关二狗不是去背尸，他是在送钱，而且他不晓得。**

考据依据（`口含钱`／`买路钱` 为真实丧俗，见下）：

| 说法 | 真实性 | 能不能当"老话"写 |
|---|---|---|
| 口含钱／噙口钱（死者口中放钱，穿红线防滑喉，入殓前抽掉；一说是给摆渡人的船钱） | 真实全国性丧俗，《周礼》"饭含"礼下来 | **能** |
| 买路钱（出殡沿途撒，买通孤魂野鬼放行、不与亡者争道） | 真实 | **能**（但"不能捡"这条只查到山西版本，**不能写成川渝老话**） |
| 手尾钱（死者留给生者的钱，一人一枚，念"放手尾钱，子孙富贵万万年"） | 真实 | **能**。注意民俗是**正面**的——沾财运，是祝福 |
| 压胜钱／花钱（铸成钱样但不流通，明清高峰） | 真实 | **能**。穷人误认成私铸假钱是合理推断（非实证） |
| 端公（川渝男巫，捉鬼冲傩；法衣、面具、师刀、牛角） | 真实 | **能**。地位偏低，治病驱邪才请 |
| 私铸钱本身带忌讳 | **查无** | 不能。只能写成"**这一枚**特殊" |
| 「死人钱拿了甩不掉／招祸」 | **查无，民俗是反的** | 不能当老话。这是**本作原创设定** |
| 「沙壳子」＝私铸钱俗称 | **查无实据** | 不能用 |
| 五通神（给横财再索命） | 真实、有学术支撑，**但分布在江南，川渝没查到** | 只能当结构灵感，不能当本地传说 |
| 「XX笔记里写过丢不掉的钱」 | **无任何古典出处** | 整个母题是原创，不能托古 |

**民俗说的是"死人的钱是祝福"。关二狗也是这么读的**（今天不对劲＝有名堂＝该去搏一搏），
然后他输光。**老话没说错，只是没说全。**

## 九、待定

- **那种钱的本名。**「私铸的」是关二狗的误判，世界里它该叫什么？
  考据未查到现成说法，需原创（已排除「沙壳子」＝查无实据）。
- 汇率的量级。
- **随机提示的具体设计**（制作人指定：后面专门做）。
- 后果分层的具体阈值与形态。
- 「主动触犯禁忌换钱」这条通道的**上限**——不设限会变成刷子。
- 那个"奇怪的人"（＝鬼）的具体呈现规则：鬼看着与常人无异，
  需要一条稳定的破绽规则，否则鬼会变成免费万能牌。
  暂定：**鬼只围着钱转**，不碰别的、不管别的。
