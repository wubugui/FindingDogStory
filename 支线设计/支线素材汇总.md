# 《寻狗记》支线素材汇总

> **文档定位**：仓库内可作为支线任务使用的素材总览。只做盘点与归类，不晋升正典。  
> **正典优先级**：用户当次审批 → `Demo制作资料/游戏总纲_设定剧情玩法.md` → 其余文档。  
> **冲突口径**：与总纲冲突以总纲为准；`废弃归档/` 禁止参考，本表不收录。  
> **整理日期**：2026.07.29

---

## 一、状态分层说明

| 层级 | 含义 | 能否当正式支线用 |
|------|------|------------------|
| **正典可选支线** | 总纲已确认，Demo 流程内可进 | 是 |
| **正典并行暗线** | 总纲／定稿承认，但不是茶馆式可选活 | 按主线暗线推进，不当普通支线接 |
| **候选草稿池** | 总纲第十六节点名，可吸收但未晋升 | 须单独审批后才能进正典 |
| **钩子素材** | 资料／系统稿有想法，未进候选名单 | 要新写方案才能立项 |
| **慎做／禁做** | 易撞主线，或总纲已废弃 | 勿硬做成独立支线 |

## 九、维护说明

1. 总纲晋升某条候选为正典后：从第四节移入第二节，并更新本表第七节状态。  
2. 新钩子先入第五节；达到「有独特民俗动作／判断」再申请进入总纲候选池。  
3. 本文件是**素材盘点**，不替代各支线独立设计稿；独立稿仍按 README 一文件／一子文件夹维护。  
4. 与总纲冲突时改本文件或提醒修订总纲，不得用本文件反向覆盖正典。
