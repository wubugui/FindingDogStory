# 城外张家院子（皮鬼儿）

> **等级**：S（候选支线，未晋升正典，需单独审批）
> **上级文档**：[支线设计文档](../系统设计/支线设计文档.md) ·《游戏总纲_设定剧情玩法》·《关卡细化_表现边界与编写规范》·《文案对话创作统一规范》·《失败累积与惩罚系统设计文档》·《身体资源系统设计文档》
> **素材来源**：《支线素材汇总》中「青楼女尸与庄家」「青楼怨灵」的合并改写；民俗母题取《聊斋·画皮》
> **定性**：**艳鬼索命**。她吃人，吃得成，而且这一夜她真的要吃他。
> **待审批裁决点**：见第九节（童子血）、第十六节

---

## 一、一句话

关二狗夜里在城墙根跟一个提灯笼的女子进了城外一座他从没听说过的院子，一心想占人家便宜；院子里他每往前伸一次手，怀里那三把火就明明白白暗掉一格——**他以为自己在占便宜，其实他就是自己走上桌的那道菜。**

---

## 二、题眼：这条支线考的是色，不是道德

> **合规论证（必须看，这是全案唯一的红线风险点）**
>
> 《文案规范》十·10 禁止"游戏替玩家给他的选择打分"。本条支线**不打分**，因为下判断的**不是游戏，是那只鬼**。
>
> 她有她的取食条件——**她只吃自己张嘴的**。这是妖鬼自身的规则（民俗里"心不动则邪不侵""色鬼不近正人"一路的老说法），和"路祭不能动""喊名不能应"是同一类东西：**世界规则，不是作者评语。**
>
> 所以全程：**没有评分、没有结算文字、没有旁白点评、没有任何角色说他不该**。游戏只做一件事——**把账单摊开摆在屏幕上，然后不管他。**

### 考验的三条硬规矩

1. **代价必须当场可见。** 藏起来的代价叫暗算，摆出来的代价才叫考验。**三把火每往前一步明灭一格，玩家全程看得见。**
2. **游戏不阻拦、不提示、不上锁。** 一句警告都不给。玩家想直冲最后一道，一路畅通。
3. **她的样子是玩家自己雕出来的。** 见第五节。

## 三、她是什么（作者机理层 · 游戏内零字）

### 1. 皮鬼儿

| 属性 | 值 |
|---|---|
| 民间叫法 | 画皮、皮鬼儿、张家寡妇、剥面娘娘（**四种叫法互相打架，游戏永不坐实**） |
| 归类 | **鬼 × 魑魅 复合**（依《实体图鉴》大类，不另造体系）：本体是无主女鬼，"皮"是她的锚，"院子"是魑魅式障眼法 |
| **危险等级** | **3**（本作可遭遇实体的最高档） |
| 她干什么 | **采阳。** 把活人身上那口阳气一口一口抽干净，人从里头冷掉、灭掉。抽干的人第二天被找到时，**尸首完好、面色如常、什么伤都没有，就是凉透了** |
| 她为什么要 | 皮撑不住了。旧皮一天天塌，得靠新抽来的阳气续着；续不上就得换一张 |
| **取食条件（核心）** | **她只吃自己张嘴的。** 人不动那个心思，她勾不住、也吃不着——不是她心善，是**她那套手艺就只对这一路人管用** |
| 有效道具 | 朱砂（有效）、桃木片（有效）、糙米（微效）、符纸（微效）、**烧酒（无效且反噬）** |
| 有效身体资源 | **尿（有效，且是最难看的解法）**；血术不适用 |
| 有效行为规矩 | 不入无名之门、不应名、不吃阴食、不吹自己的火、衣不解带、鸡叫前出门 |
| 强度定位 | **李天狗级正气可散；帕子包粘不住**（她有"皮"这个锚，不属于"没处可去的小东西"，不进入粘·跟层，红线不破） |

### 2. 死掉的人是什么样

**不写血浆、不写烂脸、不写残缺。** 采阳致死的尸首特征只有三条：

- 尸首完完整整，面色如常，一个伤口都没有。
- **凉透了，凉得不对——不是死人的凉，是井水的凉。**
- **衣裳整整齐齐叠在旁边。**

第三条是全案最狠的一个画面，也是玩家在 E0 结局里最先见到的东西。

> **纪律**：与帕子包"染"的尸相特征（**手攥紧掰不开、保持够着什么的姿势**）**彻底隔离**。皮鬼儿的尸相是"完好、凉透、衣裳叠好"，绝不能沾"手"。防玩家把信号记错（总纲六·3 时间纪律的同类要求）。

### 3. 障眼法宅邸的真身：城外义园的寄柩棚

雾津是水陆码头，客死异乡的外乡人棺材停在城外义园，等原籍家里人来接回去归葬。有的一停几年，有的再没人来接。

| 玩家看到的 | 真身 |
|---|---|
| 朱漆大门、门槛 | 义园门洞；那道"门槛"是块倒放的碑 |
| 一排厢房 | 一间间寄柩草棚，每间一口棺 |
| 堂屋、上头一块匾 | 义园祭棚；匾上是丧仪字样 |
| 满院红灯笼 | 白灯笼、招魂幡 |
| 温着的一壶酒、一桌好菜 | 供的凉水、早干了的供饭 |
| 那张床 | 一口没盖严的棺，棺板上一层新刨的木花 |
| 帐子、被褥 | 覆棺的白布 |

**她住这儿的道理**：这地方常年有人来、人来了又没人管——**寄柩棚是雾津最方便下嘴的地方**。死一个外乡人，官府不查、家里人不知道、义庄不认领，尸首往哪一放，跟本来就停在这儿的那些一个样。

## 四、七道门槛：往前一步，暗一格

**每一道门槛都是玩家亲手按下去的；每一道都有一条老规矩在挡，只是玩家不一定学过。**

| # | 玩家动作 | 卸掉的老规矩 | **屏幕上当场发生什么** | 还能不能退 |
|---|---|---|---|---|
| 一 | 跟她走、跨进那道门槛 | **不入无名之门** | 出口热点变成"外头黑得看不出是哪条路"。**三把火不动**——这一道是白送的 | 能，靠破法或天亮 |
| 二 | 喝那口温酒 | **不饮生人酒** | 挂 **酒浸血**：**破绽的文字描述全部变模糊**（现成系统副作用）。三把火不动 | 能 |
| 三 | 动那桌菜 | **不吃阴食** | **三把火 −1 格。** 无提示音、无红字，火就那么暗了一格。同时一句 OS：「身上一下子暖和了。」 | 能 |
| 四 | 报名字／属相 | **不报名不应名** | 三把火不动。但她从此会叫他名字，后半夜黑里叫三遍，**玩家须长按不应**（复用⑧林中喊名原语）；**应了 → 三把火 −1 格，且不给回头** | 能，要长按 |
| 五 | 吹灯 | **不吹自己带的火** | 画面暗，**所有视觉破绽不可见**，只剩声音和气味——**气味系统成为唯一线索**。三把火不动 | 能，只能靠嗅 |
| 六 | 解衣 | **衣不解带** | **三把火 −1 格。** 狼狈度锁死：此后不能"跑"，只能"滚"，逃出去必然光着 | 能，很难看 |
| 七 | 上那张床 | ——（没有第七条规矩，因为老辈子觉得走到这一步的人不用教了） | **进入采阳段。见第六节⑥。** | **不能** |

七道，是丧数。文档内部叫法用"七道门槛"，游戏内不出现这个词。

**三把火纪律**：本作三把火是"离死还有多远"的民俗化表达（总纲六·6）。**本关是全作唯一一处让玩家眼睁睁看着它一格一格灭、而灭的原因全是自己伸的手**的地方。这就是"考验"两个字的全部分量。

## 五、勾：她照着你的话长

**这是"考验色不色"最纯粹的机制，也是本条支线最值得做的东西。**

### 怎么运作

- 入院后的闲聊里，关二狗有若干组**吹牛／荤话选项**，内容是他自吹喜欢什么样的婆娘：
  - 「要屁股大、能生养的。」
  - 「要白净的，手上莫得茧那种。」
  - 「要会说话的，莫像街上那些泼妇。」
  - 「……要不嫌老子脏的。」
- **玩家选了什么，她后面就往哪个方向长。** 立绘换态、台词换调、连她给他添酒的手法都跟着变。
- 玩家一句荤话不说 → **她始终是初见那个模糊样子**，勾不住他，也就吃不着（这是 E1 的机理）。

### 为什么这招最狠

**破法那一刻，那张皮上的脸——是玩家一句一句说出来的。**

游戏不点破，不弹提示，不做闪回。它只是在最后那张插画里，把玩家自己选出来的那几样特征原样画上去。**认出来的人自己会凉，认不出来的人什么都不会发生。**

### 表现载体（关键：不做色情演出）

- **立绘 3 档变化**（模糊 → 合意 → 极合意），**表现在气质、姿态、衣着整洁度、说话的软硬上，不做身体描写、不做暴露立绘。**
- 门槛五（吹灯）之后**画面整体压暗，全程不演肉体**，只有声音、气味、三把火 UI 和长按提示。
- **这不是尺度妥协，是更瘆人的做法**：玩家看不见，只听得见，还眼睁睁看着自己的火在灭。

## 六、流程细化（七拍）

> 每拍按《关卡细化》强制七项写：玩家目标／进入条件／玩家操作／画面载体／声音载体／结果与状态／表现级别。

### ① 起：传闻（茶馆·白天）

- **玩家目标**：闲逛、听闲话
- **进入条件**：⑦开放段；无前置
- **玩家操作**：蹭听／插嘴
- **画面载体**：茶馆现有场景 + 两名可动 NPC 图对话
- **声音载体**：茶馆现有环境人声
- **结果与状态**：解锁夜间城墙根遭遇点；传闻池入库（第十一节，至少两版互相矛盾）
- **表现级别**：**A**

### ② 遇：城墙根（夜）

- **玩家目标**：回住处／随便走走
- **进入条件**：夜间经过城墙根或背街，且已听过任一传闻
- **玩家操作**：搭话／不搭话；搭话后选择跟／不跟
- **画面载体**：现有街头场景夜版 + **新增 NPC「提灯女子」**（走位／转身／停下 3 态）
- **声音载体**：市井噪音层**开始变薄**——远处的犬吠先没了，只剩更夫的梆子
- **结果与状态**：跟＝入支线；不跟＝E0
- **表现级别**：**B**（新增 NPC 与 3 个动作状态；灯笼用覆盖图）

> **她不主动勾引。** 她只是问路、讨个火、说"我一个人怕"。**是关二狗自己往上凑的**——这一条是全案定性：**他不是被骗进去的，他是自己要进去的。**

### ③ 入：跨门槛（门槛一）

- **玩家目标**：进去看看有没有油水，顺便有没有别的好处
- **进入条件**：选择"跟"
- **玩家操作**：走到门前 → 跨门槛（一次明确交互）
- **画面载体**：**新增场景「张家院子·华」**（夜，斜俯视可走）；跨门槛给一次极短镜头顿挫
- **声音载体**：跨过去那一下脚底**"咯噔"空半寸**；进门后**院里一点活物声都没有**（没狗、没鸡、没耗子、没虫）
- **结果与状态**：出口热点交互后只返回"外头黑得看不出是哪条路"，不可直接离场
- **表现级别**：**B**（新场景一张）

### ④ 查：自由调查（核心可玩段）

- **玩家目标**：玩家想干啥干啥。**游戏不安排目标**
- **进入条件**：入院后
- **玩家操作**：走位、调查热点、**嗅**、与她对话（含"勾"的荤话选项）；**也可以什么都不查，直奔门槛二到七**
- **画面载体**：院子场景 8–10 个调查热点 + 局部覆盖图（第七节破绽池）
- **声音载体**：**全场抽掉环境层**，只留她的说话声、布料声、酒壶声。玩家自己的脚步声因此显得太响
- **结果与状态**：每发现一个破绽，规矩本"象"层 +1；发现 ≥3 个时关二狗一句**嘴硬**的短 OS：「这院子……算球，老子怕过啥子。」
- **表现级别**：**A**（热点、对话、嗅）＋ **B**（局部覆盖图若干）

### ⑤ 陷：七道门槛

- **玩家目标**：占便宜
- **进入条件**：与她对话推进
- **玩家操作**：每道门槛一次明确选择；门槛四后追加一次**长按不应**
- **画面载体**：图对话 + 立绘（勾的 3 档）；门槛五后**画面整体压暗**
- **声音载体**：门槛五后声音成为主载体——布料、呼吸、酒壶；她的声音**从两个方向同时来**（一次，不重复）
- **结果与状态**：按第四节表逐条挂状态；三把火按表当场灭
- **表现级别**：**A**（对话、长按复用）＋ **B**（立绘 3 档、压暗滤镜配置）

### ⑥ 采阳：她真的下嘴（本关高潮 · 必须亲身体验）

- **玩家目标**：活下去。**到这一步他已经没有别的目标了**
- **进入条件**：走完门槛七
- **玩家操作**：**长按"忍住"**。屏幕上只有三样东西：黑、声音、三把火
  - 长按维持 → 火不灭
  - **每松一次手 → 火灭一格**
  - 三格全灭 → 真·濒死
  - **勾的档位越高，长按提示越弱**（极合意档下，提示图标几乎看不见）——**她越合你的意，你越忍不住**
- **画面载体**：**全黑**。只有三把火 UI 和一个极弱的长按提示。**全程不演任何肉体**
- **声音载体**：她的呼吸从耳边一点点变远（**采的是他的，所以远的是他自己**）；他自己的心跳一下比一下慢、一下比一下响；**没有惨叫、没有音乐**
- **结果与状态**：
  - 撑住到鸡叫 → **E4**
  - 三把火全灭 → **E5**（见第八节）
- **表现级别**：**A**（长按复用 ⑧原语 + 现有三把火 UI + 黑屏）——**本关最狠的一段是最便宜的一段**

> **禁止**：任何身体描写、任何色情演出、任何血浆。**黑屏 + 一个长按 + 三把火，比什么都吓人。**

### ⑦ 破：障眼法散了

- **玩家目标**：从"不对劲"变成"要命"
- **进入条件**：以下任一 —— ㊀ 主动破法（撒尿／糙米／桃木／反穿鞋）；㊁ 嗅到关键气味并选择"再闻一次"；㊂ 长按不应成功后天光将明；㊃ ⑥ 段结束后的鸡叫
- **玩家操作**：无操作，短过场
- **画面载体**：**新增全屏插画 ×1**——寄柩棚下、一口没盖严的棺、棺板上一层新刨的木花；**那张皮从耳根后头脱了一线，底下什么也没有，皮就那么撑着**。**皮上的脸＝玩家自己在"勾"里选出来的那几样特征**
- **声音载体**：环境层**一次性全部灌回来**（虫、风、远处的狗、鸡叫）——**前面被抽走的声音在这一刻还回来，是本关最狠的一下**
- **结果与状态**：进入逃离段
- **表现级别**：**B**（全屏插画 1 张 + 场景「张家院子·破」1 张）

> **她不扑、不追、不变脸。** 她只是不见了，或者还在那儿、动作停在原来那一下。非人感 > 追逐（总纲三·3）。**索命的恐怖来自"你已经被吃过了"，不是"她在追你"。**

### ⑧ 逃与余：跑回城

- **玩家目标**：活着回城，最好别被人看见
- **进入条件**：破法后
- **玩家操作**：跑（过了门槛六则动作锁为"滚爬"）；沿途**不能回头**（回头 → 三把火再暗一格，不致死）
- **画面载体**：现有城外土路夜版
- **声音载体**：他自己的喘、鞋掉了一只、远处鸡叫第二遍
- **结果与状态**：结算结局（第八节）
- **表现级别**：**A**

## 七、破绽池（象层信号 · 玩家可自行发现）

映射《实体图鉴》信号库，不另造体系。**挂酒浸血后本表所有描述变模糊。**

| # | 热点／时机 | 玩家看到／闻到的 | 信号ID | 民俗理据 |
|---|---|---|---|---|
| 1 | 跨门槛 | 脚底"咯噔"空半寸，像跨的不是门槛 | — | 门槛石实为倒放的碑 |
| 2 | 入院任意时刻 | 一点活物声都没有：没狗、没鸡、没耗子、没虫 | sig_silence | 活物先走 |
| 3 | **嗅（院中）** | 不是臭。是**新刨木花味 + 生石灰 + 桐油**——**背尸匠一闻就晓得是棺材铺的味** | 棺木霉土 | 本行感官。**他闻得出来，但他不肯往那想** |

### 关于 E5 与"无硬 Game Over"

《失败累积》全篇没有死亡档（重度后果是"落荒而逃，不是死亡"）；总纲的死亡表达是**三把火跌到濒死 → 死亡系绳**。E5 走的就是这条正典通路，**不新增死亡机制、不设读档 Game Over**。

**索命的分量靠代价撑，不靠死亡画面撑**：他活下来了，可他那三把火再也旺不回去。**这比死了更难受，也更符合本作"事后凉"的恐怖准则。**

> **香粉味复用的合规性**：总纲写明信号"靠濒死反复出现自行累积"，且只在**真正濒死**时投放。E5 是货真价实的濒死，用法正确。**纪律**：冷、淡、廉价，**不得写成温情守护**；**不得出现"信号确立"那一拍**；关二狗**全程不知道那是什么**，只当自己命大。

## 九、待审批裁决点：童子血（P0）

《身体资源系统》2.2 已写明：**童子血——初始为真（关二狗未婚）；特定剧情事件可能永久改变；一旦改变不可恢复；是特定高级仪式的前置条件。**

本条支线是这个字段目前唯一自然的落地口。

### 方案 A（推荐）：E4 与 E5 均永久失去童子血

- **当场零提示、零图标、零红字。** 它只是从此不在了。
- 直到正式版后期某个仪式要童子血／童子尿——**那时才发现没了，且不可恢复**。因果延迟到极致。
- **必须同时给足好处**：完整术层规矩、值钱货、一辈子的吹牛资本。**得失同时到账、且不对等，玩家当时以为自己赚了。**
- **必须给两句互相打架的说法**：「那玩意儿是最好的」／「瞎讲，童子不童子的，卖不出钱」——**玩家自己判断亏没亏，游戏不裁定**。

**风险**：容易被读成性惩罚。**化解**：①游戏零评价、零结算文字；②好处与代价同时到账；③失去时没有任何反馈——**它只是不在了**；④两说并列。

### 方案 B（保守）：不动童子血

改为长期撞邪 + 后期某仪式需额外"净身"手续（花钱花时间，不阻断）。恐怖减弱，完全规避误读。

> **本文档默认按 A 写。上线前须单独审批。**

## 十、规矩本词条（关二狗第一人称笔记 · 象／理／术）

**条目名：夜路上的门**

- **象**
  > 夜里有人提个灯笼问你路，问完还留你屋头坐。她那院子你从来没听说过。屋头一点活物声都没得——没狗、没鸡、没耗子。灯笼火不动，人的影子也不动。她的鞋走了一路夜路，底底上干干净净一点泥都没得。
  > 西厢那间屋头，堆了一摞叠得规规矩矩的男人衣裳，尺码都不一样。
  > 还有一样：老子是背尸的。那院子头一股新木花味、石灰味。当时闻到了，装没闻到。

- **理**（民间说法，可以互相矛盾、可以是错的）
  > 老辈子说，这路东西专抽人身上那口阳气，抽干净了人就凉了。死了的人身上一个口子都没得，脸色还好看得很，就是冷。
  > 又有人说，她**只吃自己张嘴的**——你心头不动那个念头，她勾不住你。
  > 也有人说前头全是扯把子，就是鸡叫得早不早。
  > **老子不晓得哪个对。**

- **术**
  > 一：进门之前先问一句这是谁家。她答不上来，扭头就走。
  > 二：她给的酒饭一口莫沾。
  > 三：名字属相不报。黑里头她喊你，**咬到牙不出声**，喊多久忍多久。
  > 四：自己带的火莫吹。
  > 五：衣裳莫解。
  > 六：真要破，就在她院坝头**撒泡尿**。丑是丑了点，管用。
  > 七：出来了莫回头。

> **获取分层**：E0/E1 得象＋理；E2/E3 得象＋理＋术前四条；E4/E5 得全条。**"理"层三说必须永远并列，游戏不裁定。**
