# 第七节·那盏长明灯（跑马梁背尸）

## 顶层

- **这段讲什么**：关二狗三更上牛头凼背尸，被鬼打墙逼得撂尸逃命，坠潭将死，却被一股冷香粉味拽了回来。
- **关二狗怎么变了**：从 「就当白跑一趟，反正就背个人」——嘴硬、不信邪，当它是一趟熟活 到 「这一回不要工钱了」——撂尸逃命，坠潭没死成；怀里多了个帕子包，自己不知道为什么还活着
- **关二狗的目的**：把这具尸背下山送到义庄，把剩下那一半钱拿到手。
- **体验目标**：让玩家跟着关二狗从「熟活一趟」一步步掉进「什么招都不灵」的绝望里；在以为必死的那一刻被一股说不清的东西拽回来，带着「我为什么没死」的疑问走出这一节。

## 分段表

### 1. 到凼·只有一盏灯

- **地点·时段·氛围**：跑马梁山路→牛头凼；三更；黑、静，喊一声山都不还回来，只有一盏长明灯亮着
- **关二狗的目的**：上去找到主家，把尸接过来背走。
- **开始**：一路骂着上山，当它是一趟熟活；以为凼里有主家、孝子、几盏灯几个人等着交尸
- **结束**：凼里一个人没有，只有一盏长明灯和灯旁的尸；喊了没回声；三条规矩压回后脑勺——他明白那人是知道会出事的
- **设计目的**：让玩家在还安全的时候学会护火、第一次看见三把火，并跟着关二狗从「熟活一趟」滑到「这活不对劲」。
  - 删除测试：删掉的话，后面尸重、鬼打墙就没有「这趟活从一开始就不对」的底子；三把火第一次显出来（过了界）也没地方交代，坠潭时「三把火一把把暗」玩家会看不懂。
  - 学会了：风大时按住键侧身护火（上山路上还没东西追，先在安全处练一次）
  - 知道了：看见三把火＝过了界；这趟活没人接应；那三条规矩不是随口说的
  - 感受到：从骂骂咧咧的松，到「山吃了声音」的静——后脑勺发紧
  - 得到或失去了：失去：以为有主家接应的底气。物件没变。
  - 倒推：坠潭时三把火一把把暗要让玩家看得懂，就得先在这里让三把火第一次显出来，并知道它代表什么。
- **登场角色与物件**：关二狗；长明灯；灯旁的尸（还没碰）；身上：麻绳、火把、纸钱香烛；官爷交代的三条规矩（只在他脑子里）
- **伏线**：收：前面官爷交代的三条规矩，在这里一条一条压回来。埋：长明灯为什么亮着却没人守；那人「知道会有什么」。
- **判定不属于这一段的泳道**：鼻子、重

#### 1.1（做）三更，关二狗举着火把上跑马梁；山风一阵阵把火把吹得快灭。

- **公式**：护 ＋ 手里的火把 ＋ 山风一阵阵要把火吹灭
- 玩家看到什么：上山的黑路，火把照亮一小圈；风一来，火苗被压低、快灭。这时候还没过界，画面上没有三把火。
- 玩家做什么：往山上走；风大时按住一个键，关二狗侧过身用身子挡风护火。
- 游戏怎么回应：护住了，火苗重新窜起来，关二狗骂一句接着走。
- 做错了会怎样：没护住，火把灭：要用火种重新点，点一次耗一份火种。这里还没东西追，灭了只是费火种，不会出事——所以拿这里教。
- **卡点**：不靠提示文字，玩家怎么知道「按住能护火」？我还没想好第一次怎么教（也许前面章节已经教过，这次我只拆了这一节）。

### 2. 起尸·重得没道理

- **地点·时段·氛围**：牛头凼，长明灯旁；三更；只有灯那一圈是亮的，四下死静
- **关二狗的目的**：把尸架上背，赶紧下山。
- **开始**：尸就在灯旁，瘦条条一个；他当是熟活，伸手就去架
- **结束**：尸重得没道理；他心里犯了「重」字，尸更重（重逾千斤）；他咬着牙硬背上了身
- **设计目的**：让玩家亲手把这具不讲道理的尸背上身，第一次体会到「怕会让事情更糟」。
  - 删除测试：删掉的话，鬼打墙里背上这具尸就只是个包袱，「越走越怕、越怕越重」和最后撂尸都没有分量。
  - 学会了：（卡住）背尸「越怕越重」具体怎么玩还没想好——这里应该教，但我现在写不出操作。
  - 知道了：这具尸不是普通的尸；心里一怕，它就更重
  - 感受到：熟手活第一次失手的慌——使出去的劲没有回声
  - 得到或失去了：得到：背上一具尸（从此背着走）。失去：对「熟活」的把握。
  - 倒推：撂尸那一刻要够狠，就得先让玩家亲手把它背起来、背得很费劲——背起来花的力气越大，后面撂下越痛。
- **登场角色与物件**：关二狗；那具尸（瘦、不腐不臭）；长明灯；麻绳
- **伏线**：埋：这具尸「不一样」——使多大劲都像扔进深水；心里一犯「重」字尸就更重（怕会反过来压在自己身上）。后面「那股冷贴到后颈」接这条线。
- **判定不属于这一段的泳道**：火把、鼻子

### 3. 鬼打墙·招式用尽（循环，退出条件：拍 3.4「招式使尽了。背上那具尸不腐、…」发生过）

- **地点·时段·氛围**：牛头凼往下的山路，碑石与崖松一带；三更以后，不知走了多久；黑、有风，路一直绕回来，背上越来越冷
- **关二狗的目的**：背着尸走出这段山路，下到义庄去。
- **开始**：咬牙背着尸往下走，还当是走山路
- **结束**：同一块碑石、同一株崖松一再出现；老辈人的招式挨着使完全不灵；背上那股冷贴到了后颈
- **设计目的**：让玩家把手里的招一样一样试完、一样一样落空，亲身走到「只剩撂尸这一条路」。
  - 删除测试：删掉的话，撂尸就成了胆小，不是被逼到绝路；「老辈人的招也有不灵的时候」也没处立。
  - 学会了：碰到邪门的事会弹出几个做法让你选（普通的、用规矩的、用身上物件的）。（卡住）老辈人每一招具体怎么操作还没想好。
  - 知道了：这不是迷路，是鬼打墙；老辈人的招式在这里一样都不灵；背上的东西在变冷、在贴上来
  - 感受到：从「我有招」到一招一招落空的绝望；后颈发凉
  - 得到或失去了：失去：糙米（撒掉了）、一招一招的指望。
  - 倒推：坠潭前玩家得先「什么招都试过、全落空」，濒死被拽回来才像白捡一条命；也得先知道背上那东西是冲着他来的。
- **登场角色与物件**：关二狗；背上的尸；碑石、崖松；火把；随身：糙米、一截桃木、脚上的鞋；不露面的「哪位大爷」
- **伏线**：收：起尸时「怕就更重」那条线，在这里压到顶。埋：尸不腐、不臭、冷得反常；那股冷会自己贴上来。

#### 3.1（做）背着尸往下走，走了不知多久，前头出现一块碑石、一株崖松。

- **公式**：走（背着尸、举着火把下山） ＋ 下山的山路 ＋ 山风一阵阵要把火把吹灭；路会悄悄绕回来
- 玩家看到什么：黑的山路，火把只照亮一小圈；身上三把火显着（还在界里）；走一阵，前头出现一块碑石、一株崖松。
- 玩家做什么：推着关二狗往山下走；风大时按住键侧身护火。
- 游戏怎么回应：护住了，火就回来；走过一段，碑石、崖松出现在前头，关二狗嘴里嘀咕一句「这两样刚才过过」。
- 做错了会怎样：没护住，火把灭了：要用火种重新点，点一次耗一份火种。火灭着的时候，阴间的东西就敢近身，三把火会暗。
- **卡点**：背着尸走路时「越怕越重」怎么玩，还没想好（走得慢？护火更难？不知道）。这一拍先只用已经想好的「护火」。

#### 3.2（做）又走一程，前头还是那块碑石，那株崖松。

- **公式**：走（想走出去） ＋ 同一段山路（碑石、崖松） ＋ 不管往哪走，走一程都回到碑石前
- 玩家看到什么：又走一程，前头还是那块碑石、那株崖松，和刚才一模一样。
- 玩家做什么：接着往下走（可以换个方向试）；风大了照旧要护火；可以按键「闻一闻」。
- 游戏怎么回应：怎么走都绕回碑石前；闻一闻——什么味都没有（尸不腐不臭）；再见到碑石时，关二狗自己认出来：「鬼打墙。」
- 做错了会怎样：这一拍走不错——怎么走都回来。代价只是拖得越久，风吹火把的次数越多（没护住就耗火种）。
- **卡点**：路到底怎么绕回来（地图怎么接）我没想过；要走几遍关二狗才认出来，原文是第二次再见到碑石时。「做错了会怎样」我其实答不上来，这一拍也许该归「看」，拿不准。

### 4. 撂尸逃命·顺手一抓

- **地点·时段·氛围**：同一段山路往下，靠崖边；三更后；黑，连滚带爬，慌不择路
- **关二狗的目的**：工钱不要了，活命要紧，往山下跑。
- **开始**：招式用尽、后颈贴着冷，他崩溃了
- **结束**：尸撂在路上，他在逃；怀里多了个沉甸甸的旧帕子包（绊到时顺手抓的）
- **设计目的**：让玩家看着关二狗头一回弃活逃命，并且在最狼狈的时候还贪手捡了帕子包——把后面「没死成」的因埋下去。
  - 删除测试：删掉就没有帕子包，坠潭时没东西拽他回来，全游戏第一次「濒死被拽回」就不成立；「这辈子头一回不要工钱」的转折也没了。

### 5. 坠潭·香粉味

- **地点·时段·氛围**：崖下深潭，水里；三更后；水黑、冷、往下拽，什么都看不见
- **关二狗的目的**：扑腾上去，活命。
- **开始**：连滚带爬往下跑，脚下一空，坠进崖下深潭
- **结束**：三把火暗到底、真要死的那一刻，一股冷的廉价香粉味浮起来——他没死成，自己不知道为什么
- **设计目的**：让玩家在以为必死的那一刻被一股说不清的东西拽回来，带着「我为什么没死」的疑问出这一节。
  - 删除测试：这是整节的高潮，也是全游戏第一次「濒死被拽回来」；删掉，后面所有「他为什么死不了」的线都没了头。
  - 学会了：三把火暗到底＝死（看懂就行，这段不教新操作）
  - 知道了：有一股说不清的东西在他要死的时候拽了他一把（冷的香粉味）；关二狗自己不知道为什么没死
  - 感受到：往下沉的无力 → 以为必死 → 被拽回来的错愕
  - 得到或失去了：失去：三把火一把一把暗到底（濒死）。得到：一条捡回来的命，一个疑问。
  - 倒推：这一段就是高潮本身。它需要前面：三把火已经显过（第1段）、什么招都不灵（第3段）、帕子包已经捡了（第4段）。
- **登场角色与物件**：关二狗；深潭；怀里的帕子包；三把火；那股冷香粉味
- **伏线**：收：帕子包（上一段捡的）在这里第一次起作用；三把火（第一段显出来的）在这里一把一把暗。埋：香粉味是谁、为什么救他——全游戏第一次，这里不解释。
- **判定不属于这一段的泳道**：火把、重
- **之后**：这条线在这里结束

## 玩法

### 护火（举着火把过风）

- **成立的时候，玩家会**：玩家看见火苗被风压低，会自己停下来、按住键侧身护火，等火回来了再走；不会顶着风硬走。
- **做错了，游戏会**：火把灭掉：得停下来用火种重新点，点一次耗一份火种；火灭着的时候阴间的东西敢近身，三把火会一把一把暗。
- 起（教：安全地学会）：1.1 三更，关二狗举着火把上跑马梁；山风一阵阵把火把吹得快灭。
- 承（用：正常使用）：3.1 背着尸往下走，走了不知多久，前头出现一块碑石、一株崖松。
- 转（变：规则被扭一下）：3.2 又走一程，前头还是那块碑石，那株崖松。
- 合（极：用到头或崩掉）：（空）
- 备注：「合」这一格我没有拍可放——这一节里火把最后怎么了（撂尸逃跑时、坠潭时），原文没写，我也还没想。「转」放的是鬼打墙里那一拍：护住了火也走不出去，拖得越久越耗火种。

### 遭遇（碰到邪门事，挑一个做法）

- **成立的时候，玩家会**：碰到邪门的事，玩家会先把弹出来的几个做法看一遍（普通的、学过的规矩、身上的物件），挑一个试；一招不灵会换一招再试，而不是乱按。在这一节，玩家试到第三四招时会自己反应过来：这回什么招都不灵。
- **做错了，游戏会**：选的那一招搭进去的东西就搭进去了（糙米撒了就没了）；在这一节，选哪一招都一样：再走一程，碑石还在前头。
- 起（教：安全地学会）：（空）
- 承（用：正常使用）：（空）
- 转（变：规则被扭一下）：3.3 碑石又在前头。他身上有糙米、有一截桃木，肚里有老辈人传的招。
- 合（极：用到头或崩掉）：4.1 招式用尽，那股冷贴在后颈上。
- 备注：「起」「承」空着：遭遇怎么玩应该在前面的章节就教过、用过了，这一节里没有教的拍，这次我也只拆了这一节。「转」＝鬼打墙：平时挑对了就灵，这回每一招都不灵。「合」＝招式用尽后撂不撂尸——但这一拍是不是也用「弹出做法让玩家挑」的样子来做，我还没想好。老辈人每一招具体怎么操作也没想好。
