# Demo H3 镜头卡后半 · V15–V22

本文件是**全部正式版与阿秀图片完成之后**的 H3 执行准备；截至 2026-09-25 尚未提交视频任务。剧情顺序以 `Demo制作资料/游戏总纲_设定剧情玩法.md` 第九节为准，画面与比例以链接的 GameDraft 真实运行帧为准。逐段哈希、触发路径和未实装动作见[首帧审查矩阵](Demo_H3首帧审查矩阵.md)。

Hub 直连 `http://denghong01:8765/` 的当前 `/guide.md` 和 `/capabilities.json`：`backend=h3`，`mode=fl2v` 最多一张首帧，24 fps，帧数由服务向上对齐为 `17k+5`、最大 362；`negative_prompt` 无效。本组预案按每段约 5 秒、固定 4:3 游戏画幅写，实际帧数、分辨率、上传 file ID 和任务 ID 在最终图片验收后锁定。视频输入优先真实运行帧；通过审查的 Hub Qwen 模拟图仅在确实需要补充既有剧情瞬间时使用。生成后逐帧复查首尾帧和比例，失败片保留记录并重抽。

## 开跑前判据

1. 先等正式版、阿秀生平所需全部双图补齐并验收；本文件不触发 H3。
2. 每段锁定真实首帧文件 SHA256、Hub 上传 file ID、prompt、请求 JSON、幂等键、任务 ID；不得把旧 GPT→Qwen 再编辑图或判退候选充作首帧。
3. 若 H3 在固定画幅中改变 HUD、建筑结构、角色身份或人物/道具比例，即使画面气氛好也判退。
4. 回程进度条、对白文字、最终黑屏等若由 H3 难以稳定保持，应在最终验收时如实记录；不能把生成错误说成游戏原生画面。
