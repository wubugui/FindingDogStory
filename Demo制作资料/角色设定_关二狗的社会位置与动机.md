# 角色设定 · 关二狗的社会位置与动机

> **文档定位**：补《游戏总纲》第七节·一「关二狗」缺的那一半。总纲写的是**性格**（贪、怂、鲁钝、嘴硬），本文补的是**位置**——他靠什么吃饭、每天在干什么、被什么推着走。
>
> **正典层级**：本文为**待审批设定稿**。经用户确认后，第三、四、五、六节回写入总纲第七节·一，第七节的回改点再落到《关二狗的故事》与相关关卡脚本。**未经审批不得当正典引用。**
>
> **本文不改**：总纲第十四节·三关二狗红线一字不动。所有结论必须在"贪、怂、鲁钝、嘴硬、不能突然变聪明正义"之内成立。
>
> **已废弃的旧方案**（V1，2026.08.29 用户否决，记档防复活）：❌"上册子／被记一笔名字"式深层动机——那是识字人的自我实现叙事按在不识字的人头上，精英视角，作废；❌"册子"意象的措辞方案，作废；❌先锁"义庄柴房"住处再定人，顺序反了，作废；❌与阿秀"名字"主题的对位联动，作废。

## 一、诊断：问题不是"没有动机"，是"没有位置"

现稿给关二狗的是一整套**性格动机**，缺的是**位置动机**。缺了后者，人物就退化成一台在正确时间出现在正确地点的摄影机。症状三条：

### 1. 活全是"送上门"的，他一次都没有主动去找

盘点《关二狗的故事》全篇的推进方式：

| 拍 | 谁来推 |
|---|---|
| §五 五百文 | 面生雇主在卡卡角角里**喊他** |
| §九 第一单假道士 | 婆子**找上门**，钱已经拍在桌上 |
| §十 枯井怪狗 | **有人报信** |
| §十 义庄两尸 | 管事的**连夜来寻他** |
| §十 城隍庙守夜 | **被派**去守 |
| §十一 喊名 | 面生雇主**让他跟脚帮走一趟** |
| §十二 三十块大洋 | 洋女人**在街角等他** |

七拍，七次别人上门，他从头到尾没有一次是自己走出去把活找回来的。观众看久了会得出一个准确的结论：这个人不需要活着，他只需要在场。

### 2. 场与场之间没有他自己的因果

§二"盘算从不超过当天"这一笔是对的，是穷人的真实，保留不动。问题在全稿没有第二层力压上去：任何一拍拿掉，前后都能接上——这是摄影机的判定标准。

### 3. 他没有非接不可的活

不欠谁、不等谁、不缺哪样具体东西。每个活他都可以不接；他接，只因为剧本需要。

### 4. 全稿唯一做对的地方，就是解法的方向

**§六赌坊**：定金输光→义庄那另一半钱成了唯一指望→只能真上山。这一拍有劲，因为它头一回让他**被背后的东西追着走**。

⚠️ **解法的方向由此定死：推力放在背后，不在前面。**给底层人物造动机的错误做法是往他前头吊一个愿望（理想、志向、被承认——那全是识字人的叙事）；正确做法是把他背后的追兵写实：饿、账、赊、上一步花掉的钱。赌坊这个手法是对的，只用了一次，要把它从一次性剧情补丁升级成他常年的生存状态。

## 二、史实底盘：清末民初川东水码头，最底下那一格每天在干什么

（口径：地域**川东**，用户已确认（"川南"为口误）；年代取清末民初连续段，这一段川东底层社会结构跨清民之交基本没变。出处见第八节史实注。）

### 1. 能挣饭的行当，全被行帮把着

十九世纪中后期的重庆城，码头、挑水、抬轿、纤夫、力夫都成行成帮，有"局""号"一类组织，同治五年由昆明迁渝的麻乡约到二十世纪初已是脚力行当的大佬。散工要进这些行当挣钱，得挂号、拜码头、有人保、按规矩分地盘。

**对本作的意义**：雾津不是一个"谁想干活都能干活"的地方。**没挂号的人挣不到有组织的那份钱。**

### 2. 袍哥的门槛是制度性的，不是运气

嗨袍哥（入会）要"身家清白、己事明了"，讲究三代没有夹灰卷口；干过被视为不干净行当的人不收。没入会的叫"空子"。

**对本作的意义**：关二狗进不去**不是没人引荐，是他这行当根本不合格**。他的处境从"倒霉"改成"注定"。

### 3. 连讨口子都有组织

清代把乞丐编入保甲，选立丐头管束，查造丐户牌册。

**对本作的意义**：《关二狗的故事》§一"连讨饭的都成帮结伙有人罩着"——这句是史实，不是修辞。他比叫花子还低一格：叫花子有花子头，他谁都没有。

### 4. 收尸抬埋这一行，本来就是从最贱那一层里挑人

仵作亦称行人、团头，本出自旧时最被贱视的一层，后与丧葬抬埋合流成行。杠房（抬杠出殡）自有班子，是有组织的那部分。

**对本作的意义**：**背尸这门手艺，正是把他钉死在贱籍那一格的东西。**手艺是他唯一的饭碗，也是他这辈子上不了岸的原因——一样东西同时是命根和枷。

### 5. 装道士这件事，在当时几乎没有门槛

南方民间道教以火居道士为主，自有家室产业，做道场、驱邪、禳解按堂收钱；西南又有端公一路，平时是种地的、背盐的、卖酒的，有事才凑班跳神，师徒临时搭伙。

**对本作的意义**：**装道士不是异想天开，是钻一个当时真实存在的空子。**这行本来就人人兼业、没有统一凭证、外人分不出真假。"假道士"由此从荒诞设定变成合理生态。

### 6. 钱的分量

无手艺的杂役短工日工钱约三十到五十文；四川遂宁一带帮工月工钱有作五百文之数的记载。

**对本作的意义**：神秘人开的**五百文≈一个没手艺的人白干十天半月**。§五他为什么不能不接、§六为什么敢一把梭哈，全在这个数上。这个分量要让玩家感觉到，不能只是个数。

### 7. 底层没有纯娱乐时间

底层人的消遣是能顺便社交、能白嫖、能捡到消息的那种：茶馆、看热闹、听书、赌钱。茶馆尤其要紧，因为**多数底层人不识字，消息只能靠听**。

**对本作的意义**：茶馆对关二狗不是消遣场所，是**他的活市和他的报纸**。他不识字（§二已定），不去茶馆就没有活、没有消息。

## 三、身份裁定：他到底是干嘛的

### 一句话

**雾津吃死人饭的编外散工。**

丧葬这套行当（杠房、义庄、抬埋、装裹）的最外围：行当里有组织、有油水的活——正经出殡、大户抬杠——轮不到他；行当不要的活——**无主的、凶死的、夜里的、犯忌讳的、主家不肯露面的**——从行当的缝里漏下来，落到他这种人手上。

丧葬本身已是贱业；他连这个贱业的"行"都没入——没东家、没保人、没行规罩他。**贱业之下的编外，是他的准确坐标。**

丧葬活不是天天有，闲时靠嘴和腿凑零钱：跑腿、送信、送不能问的"包袱"、红白事帮闲、看热闹起哄。§三写的全部内容（背尸搭尸装裹抬埋、扒尸捡漏、带货）原样装进这个框，一件不用改。

### 生态位：行帮不接的活的五个特征，就是他的饭碗边界

| 特征 | 为什么行帮不接 | 为什么归他 |
|---|---|---|
| **脏** | 有别的活干就不干这个 | 他没有别的活 |
| **犯忌讳** | 犯了要出事，出事没人担 | 他一个人，出事也没人管 |
| **夜里** | 白天的行市不做夜活 | 他没有家，夜里本来也在外头 |
| **单人** | 拆不成行帮的份子 | 他本来就只有一个人 |
| **无名无凭** | 主家不肯留姓名的活，行帮担不起 | 他没有名字可留，正合适 |

附带一条他自己的定价逻辑（§二已有，点明即可）：**别人一犹豫，他眼睛先亮**——不敢接的活，工钱才抬得上去。晦气就是他的行情。

### 由此得到的最关键推论

**关二狗撞上超自然，不是巧合，是职业必然。**

雾津城里出了不干净的活，一层一层往下推，推到最后没人接了，才落到他手上。**他站的位置，就是这座城把邪门事扫出去的那个口子。**总纲第二节"假道士泡在真鬼里"这句卖点，到这里才有了地基——他不是运气差，是他吃这碗饭。

七次"雇主上门"从此也都有了解释：**上门的人是找不到别人才来找他的。**这一层要在文案里透出来（雇主的迟疑、压价、"实在没人接了"的口气），不能只当巧合放着。

## 四、他每天在干什么

底层散工的一天不是无所事事，是**在几个固定地点之间转圈讨活**——"闲逛"就是他的上班。可直接作为城镇玩法循环的骨架（对应总纲第十二节·九）。

| 时辰 | 地点 | 干什么 | 图什么 |
|---|---|---|---|
| 天没亮 | 义庄那头 | 晃一圈，看有没有尸、有没有守夜的活 | 他脸熟，晦气活先想到他 |
| 早上 | 码头 | 挂号的挑完大宗，剩下的零碎才轮得到他捡 | 一趟几文，够一碗 |
| 晌午 | 茶馆 | 赊茶、打滚、听消息、等人来喊 | 活市＋报纸：不识字，消息只能听 |
| 下午 | 街市 | 跑腿、送包袱、帮闲、顺手牵羊、看热闹 | 零钱，兼探路 |
| 入夜 | 有活：守夜／背尸／抬埋；没活：赌坊 | — | 夜价高一截 |

### 住处：跟着活走（先定人，住处只是推论）

他这种编外散工没有"住处"这个词，只有"今晚睡哪"：

- **有守夜的活，活就是床。**守夜给他的从来不只是工钱，还有一夜的瓦片和灯火——这是他接守夜活的另一半理由，不用台词，玩家看他睡在灵堂边就懂了。
- 没活，就是桥洞、庙檐、河边窝棚。
- 义庄那头他脸最熟，柴堆边蹭一晚是常事——但那是蹭，不是住。义庄没给过他任何名分，那不是"他的地方"。

**哪儿都能睡一晚，哪儿都不是他的。**游戏里给不给他一个固定睡点，是城镇玩法结构问题，随关卡定，不在人设层锁死。

### 钱观：为什么钱一到手就散

不是笨，是没有攒钱的条件：

1. **没地方放。**没有家、没有柜、没有能锁的箱子，钱只能揣在身上。
2. **揣着招祸。**身上有钱的叫花子会被打、被讹、被"借"走不还。
3. **日结工的钱观。**今天的钱是今天挣的，明天的饭明天再说。攒钱是有明天的人才干的事。

所以钱对他不是数字，是**当几个时辰人的门票**，当天花当天光：一碗带臊子的、赌两把、充一回大爷请一圈——§六他赢钱时"扬言今黑了老子请客"就是这个花法的正典演示。赌坊门卫那声"看走眼咯，二哥"，是雾津唯一一件他花钱买得到的体面，也就买得起几个时辰。**这一条给§六翻案：他去赌坊不是角色犯蠢，是阶级习惯。**

## 五、生存目的与活动动机

### 1. 推力在背后，不在前面

他的生存目的就是最本分的那个：**今天两顿，晚上有个地方缩。**不用发明更高的。

推他走的不是前面吊着的愿望，是背后追着的东西：

- **饿是钟表。**§二已写死：天没亮饿醒，睁眼头一件事是盘算今天。这就是他的开工铃。
- **账是缰绳。**赊的茶钱、赊的桃木剑（§十三已有）、讨不回的工钱——他永远处在"欠一点"的状态。断赊比欠债可怕：欠债只是欠钱，断赊是被这条街除名。
- **上一步的窟窿是推手。**定金输光→只能真上山；行头赊了→只能把向导装到底。每一大步都是被上一步花掉的钱推出去的，不是被理想拉过去的。

### 2. 嘴是他的第二门手艺

吹牛不是性格花边，是**生产工具**。他没拳头没靠山，一身本事全在嘴上（§二已定）：讨价、圆谎、把经历吹大换茶换脸色。说书场是他进货的地方（旱魃、镇、符、墨斗、黑狗血——"这些往后唬人能用"，§四原文），茶馆是他出货的摊。他听书听得入神，一半是穷人的热闹，一半是**匠人在记料**。

### 3. 装道士是卖嘴的升级，不是身份的追求

链条每一环都是贪字加行情，没有一环需要"内心成长"：

1. 婆子那单让他头一回发现：**念几句词的钱，抵得上背几趟尸**——同一个贪，从卖力气升到卖嘴。
2. 行情允许：这行本来真假混杂、没有凭证（第二节·5），冒充成本约等于零。
3. 洋人重金放出来，全城能人都去凑；他蹲在人群外看明白"就他这副样子谁也不会选他"（§十原文）——**那就装**。装道士皮是他唯一凑得出的本钱。
4. 名头是别人喂大的（"徒弟的徒弟"传成"大弟子"，§九原文），他只消顺着接住——顺水推舟不要本钱，这也是贪。

### 4. 活动动机的最终答案

他图的从来只有一样：**钱，以及钱当天能换来的那口热的、那把骰子、那声二哥。**

拉他进深山的不是使命，是三十块大洋（抵他混几年）；让他退不回来的不是执念，是花掉的定金和赊掉的行头。

### 5. 纪律红线

- ❌ **不许给他任何对自身处境的抽象总结。**不许出现"老子这辈子就想……"式自陈，不许把§二那句"凭什么不是我"升格成纲领——它保留为一闪而过的眼红，是情绪，不是志向。
- ❌ 不许任何形式的"被承认""被记住""找归属"式动机描写，台词、OS、设计文档一律不用这套词。
- ✅ 内心 OS 按规范只有三样：要不要钱、跑不跑得脱、这个能不能吹。够用了。

## 六、社会关系

### 总括一句

**满城脸熟，无人相干。**

他认得全城的门路，全城也认得他（"那个背尸的""那个嘴贱的"），但没有一个人对他负有任何义务——没有东家、没有保人、没有师父、没有帮。他的每层关系都是"下回有这种活还找他"的交易记忆，不是名分。

| 谁 | 关系 | 说明 |
|---|---|---|
| **义庄黄大师／管事** | 脸熟 | 晦气活、没人接的活先想到他；给他安过属相，那是随口一句，不是收留。⚠️ 不许写成父辈温情或半师徒。 |
| **茶馆掌柜** | 赊账关系 | 他每天要看的脸色；随时能断他的赊、撵他出门 |
| **张叨叨（说书先生）** | 单向的抄 | 他全部话术家底的进货处。两人不必认识、不必有交情，他自己都不觉得那是"学" |
| **李瞎子** | 同场吃饭的江湖同行 | 一个卖卦一个卖力气，互相拆台。唯一当众叫破他行当的人（"香灰味压起尸臭味"） |
| **脚帮** | 共过事，不接纳 | 平起平坐但不是自己人——这根刺比被踩还难受 |
| **讨口子那伙** | 结过仇（§一） | 连叫花子都有花子头，他没有 |
| **袍哥的小弟** | 使唤对象 | 踢他、用完不认人；他眼红的就是那种"没人敢动你" |
| **做"带人"生意的相熟** | 塞活给他（§三已有） | 给钱痛快、不能问——正是"无名无凭"那类活的常规主顾 |
| **赌坊** | 只认钱 | 雾津唯一一个他有钱就被当人的地方 |

## 七、把"被叫来"改成"被推着去"：三处小改

不动剧情骨架，只把背后的推力和行当的缝写进画面。

### 改一：开场先看见他讨活而讨不着，再让神秘人喊他

被撵出茶馆 → 卡卡角角有人喊他，中间插一小段：码头零碎被挂号的挑完了、赊茶被掌柜挂了脸、答应的工钱讨不回来。**效果**：五百文出现时，玩家自己会算出"他不可能不接"。贪还是那个贪，但有了压强。

### 改二：给他一笔常年在身上的赊账

茶钱、桃木剑（§十三已有）、几处零碎加起来压着他，随时可能被断赊。不用印子钱——利滚利会把戏推向另一种类型，还得多一个债主。

### 改三：给"雇主上门"加一层来路

七次上门至少三次让玩家听出"是找不到别人才来找你"：婆子先说请过别人、人家嫌钱少不来；义庄管事现稿已有范本（"正经先生这个钟点请不动，请来了也是大价钱。有人提了关二狗：背尸的，胆大，价便宜"）——**保留并往其他几拍复制这个口径**；洋女人那拍要让玩家知道先凑上去的真道士、脚帮把头为什么没成。

**效果**：他不再是"被剧本选中的人"，而是"这座城最后剩下的那个人"。
