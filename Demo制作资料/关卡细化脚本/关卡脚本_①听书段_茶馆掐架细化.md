## 场景基本信息

- **地点**：雾津城 · 茶馆内
- **时间**：白天（午后）
- **视角**：45° 等距俯视
- **在场人物**：关二狗、说书人、**李瞎子**、**脚夫甲**、茶馆小二
- **前置**：说书开场 cutscene（李天狗战僵尸剪影）结束，镜头平移回落座的说书人，再缓缓平移到茶馆角落
- **本段作用**（依总纲第九节①）：

  2. 立住茶馆是信息中心
  3. 立住关二狗爱吹、爱蹭、没地位

## 镜头 A · 落到角落（建立人物，无操作）

### 画面
镜头从说书人处缓缓平移，扫过几排长凳上的听客，最后落在茶馆最偏的角落——靠柱子的地上。

**关二狗蹲在地上，不是坐长凳。**

- 衣裳打了好几个补丁，洗得发白
- 手里捏着半块粗粮饼，啃了一半
- 身体微朝说书人方向倾，听得入神
- 脚边放着一根磨得光滑的扁担

**斜对面靠门的位置，李瞎子也在**。他不坐长凳，坐一只倒扣的小竹凳，面前地上摆着卦筒，眼睛闭着，头微微偏向说书人的方向。

> ⭐ **蹲 vs 坐 = 阶级**（规范第一章·4）。这一镜不解释，只呈现：坐长凳的是客，蹲着的是他。

### 声音（市井噪音层 · 必须写足）
- 说书人：「最后只见李天狗一道符，生生把那旱魃镇进地里！」（旱魃版，台词以配音稿 voice_009 为准；旧"斩飞僵"词作废）
- 醒木「啪」
- 底噪：嗑瓜子、茶碗磕桌、掺茶的长嘴壶水声、两桌人低声讲价、门外挑担吆喝

> ⭐ 这一层是恐怖的本钱。② 夜背崖墓尸的"没有声音"，是靠这里的"太有声音"垫出来的。

| 进入条件 | 说书 cutscene 结束 |
| 玩家操作 | 无，镜头自动 |

## 节拍 2 · 李瞎子闻出来（点火 · 无操作）

### 动作
关二狗听得来劲，往斜对面挪了半步——离李瞎子近了。

李瞎子没转头，把卦筒往怀里拢了拢。

### 对话（低声，只有近处听得见）
> **李瞎子**（慢悠悠，不转头）：
> 「娃儿，你挨着我坐，我这卦筒都要发潮。」
>
> **关二狗**（没听懂，警觉）：
> 「关你锤子事。」
>
> **李瞎子**（掐了掐指头，鼻子动了一下）：
> 「香灰味压着尸臭味……你是杠房那头过来的哇？」

### ⭐ 本作第一个"一刷 / 二刷反过来"的暗扣
玩家一刷会读成「这瞎子有神通」。
真相是：**他就是鼻子好。** 关二狗身上带着职业味——香灰压尸臭是杠房的常规做法。
游戏永不确认是哪一种。

> ❌ 此处不出现任何超自然。① 只立市井，恐怖留给 ②。
> ❌ 李瞎子不把话说透，不给结论，不预警。

| 项 | 内容 |
|---|---|
| 玩家目标 | 无（被动挨了一句） |
| 进入条件 | 节拍 1 结束或玩家主动靠近李瞎子 |
| 玩家操作 | 无 |
| 画面载体 | 图对话 + 双方立绘（李瞎子闭眼、掐指） |
| 声音载体 | 底噪不变（**这里不要压低，还是很吵**）、卦筒木响 |
| 结果与状态 | 触发节拍 3 的选择；置 `met_xiazili` |
| **表现级别** | **A**（图对话 + 立绘 + 道具音） |

## 节拍 3 · 关二狗自己引爆（★玩家选择 · 保底触发）

### 选择（三选一）

**【A · 往上吹】**
> **关二狗**（一下站起来，声音拔高）：
> 「背尸咋个了？老子背的是阎王岭那具邪尸！老搭尸的都不敢挨手！」

**【B · 硬顶】**
> **关二狗**（梗着脖子）：
> 「正经手艺！给钱就干！你算你的命，管我做啥子。」

**【C · 装没听见】**
> 关二狗把脸别开，往饼上啃了一口。
> **李瞎子**（不紧不慢，音量没变，但周围刚好静了半拍）：
> 「……杠房那头的味道，散得慢哦。」
> **关二狗**（受不了）：
> 「老子背尸咋个了嘛！」

### ⭐ 保底设计
**三条路都会让"背尸"这两个字被周围人听见。** 与 ⑧林中喊名 X 点① 同构——每个玩家都至少欠下一笔账，区别只在欠多大。

### 后果差异（不打分，只是"还在那儿"）

| 选择 | 声量 | 后续影响 |
|---|---|---|
| A 往上吹 | 最大 | 名声传得最快（④婆子家上门更早、更信）；小二最凶；⑦置办行头时茶馆一带认得他 |
| B 硬顶 | 中 | 中等 |
| C 装没听见 | 最小 | 名声起点最弱；但**照样被赶** |

> ❌ 不掉好感度、不冒"其实他也不想的"、不给钱给爽。**游戏不给这个选择打分**（规范第一章·6）。

| 项 | 内容 |
|---|---|
| 玩家目标 | 保住面子 |
| 进入条件 | 节拍 2 结束 |
| 玩家操作 | 三选一 |
| 画面载体 | 图对话 + 选项 + 关二狗立绘（得意 / 嘴硬 / 心虚三态） |
| 声音载体 | **关二狗的声音盖过说书人**；C 选项处有半拍环境静音 |
| 结果与状态 | `mingsheng_qidian` = 强／中／弱 |
| **表现级别** | **A**（对话选择系统已有） |

## 节拍 4 · 脚夫甲放大（同阶层踩同阶层）

### 对话
> **脚夫甲**（隔一张桌，不耐烦地扭过头）：
> 「吹嘛你就。背死人的也来听书？」
>
> **关二狗**：
> 「咋个了？老子给钱蹭的茶！」
>
> **脚夫甲**（对旁边人，声音故意大）：
> 「哎哟——挨着他坐的，回去记到洗手哈。」

### ⭐ 底层踩底层
脚夫甲跟关二狗同一层，甚至更穷——**但他有一份不沾死人的活**，这就够他踩了。嫌他脏的不是长衫客，是跟他一样穷的人。这比阶级俯视更扎人。

### 群体反应（❌ 旧稿的 C 档写法已作废）

**不做**：所有听客齐刷刷挪开／有人捂鼻／有人端碗躲远（表现边界规范第八章明确点名要改）。

**改为**：

1. **茶馆人声突然低下去**——不是全静，是塌了一层。
2. **两侧传来椅脚拖地声**（离屏音效，各响一次，间隔不齐）。
3. **一名可动茶客起身，端着碗换到远处的桌子**（单个 NPC 走位，全场唯一的可见位移）。
4. 低声窃语两句（离屏）：「背死人的？」「难怪蹲角落……」

### 关二狗的反应
- 他后知后觉才发现周围空了一圈
- 嘴张了张，想找补，话已经收不回来

| 项 | 内容 |
|---|---|
| 玩家目标 | 无（承受后果） |
| 进入条件 | 节拍 3 任一选择结束 |
| 玩家操作 | 无 |
| 画面载体 | 图对话 + 一名可动茶客走位 |
| 声音载体 | **人声塌一层** + 椅脚拖地 ×2（离屏、不同步）+ 窃语 ×2（离屏） |

## 节拍 5 · 小二撵人（❌ 无肢体接触版）

### 动作
小二从柜台那边颠颠儿跑过来，站定在关二狗面前，叉着腰。

### 对话
> **小二**（拔高声音让周围都听见）：
> 「走走走！背死人的也往茶馆里钻？」
> 「沾了一身晦气，熏到其他客人咋个办？」
>
> **关二狗**（软了，但嘴不能输）：
> 「哎哎哎！莫动手！老子给钱还不行迈？」
>
> **小二**（冷笑）：
> 「谁要你的钱？**你蹲过的那块地，哪个还敢挨？**」
> 「快走快走，莫逼老子喊人。」

> ⭐「你蹲过的那块地」——蹲的阶级符号在这里收账，一句话把他钉死在底层。

### ⭐ 肢体接触的替代方案（表现边界规范第八章）
旧稿「小二伸手搡肩膀」需要专属接触动画，**本版不做**。改为：

1. 小二**逼近**（普通行走，走到与关二狗接近重叠）
2. 重叠前一帧**白闪**
3. 同步播**衣料摩擦声 + 一声闷响**
4. 关二狗**后退半步**（一个位移，不做接触动作）

### 关二狗的反应（一拍只抓一个主要动作）
- 想顶嘴，看了看小二的身板，又看了看周围没人帮他说话
- **只保留一个主动作**：把手里的半块饼往怀里一揣。其余情绪交给立绘与台词。

## 节拍 6 · 门口嘴硬（★玩家选择 · 脏话方向性）

### ⭐ 铁律：狠话必须退到门口／门外才喊
规范第五章·1：**关二狗的狠话永远冲着不能还嘴的方向喊。** 在小二面前不许喊，必须退出去、拉开距离、回头喊。这是「怂」的表演，不是「横」的表演。

### 动作
关二狗慢吞吞站起来，拍了拍屁股上的灰，抓起脚边的扁担，一步一步往门口退。**退到门槛外，才回头。**

### 选择（三选一）

**【A · 撂狠话】**
> 「走就走！等你们哪天屋头撞了煞、遇上真僵了——」
> 「莫来求老子！」

**【B · 脏】**
> 「你娃儿等到起！」
> （又退了两步，确认小二没追出来）
> 「给老子爬！」

**【C · 憋着】**
> 关二狗什么也没说，转身就走。
> 走出七八步，才对着空气骂了半句：
> 「……龟儿该背时。」

> ⭐ 三条路的共同点：**没有一句是当着人说的。** C 是最狠的一版——它把"怂"演得最准。

### 收尾画面
- 说完转身就走，走得挺快，像是怕小二追出来
- 临出门瞪了一眼，正好跟说书人方向对上——**说书人根本没看他**，醒木一拍，接着讲下一段
- 茶馆门「吱呀」关上

### ⭐ 声音收尾（本段最重要的一笔）
门关上后，镜头停在门外两秒。

**门里的人声重新涨起来**，热热闹闹，好像刚才这事根本没发生过。

> 这是「活人比鬼吵」的第一次示范，也是 ② 的反向预演：
> **① 教玩家茶馆的声音长什么样；② 崖墓上没有这个声音，才吓人。**

### 李瞎子的最后半句（★三段扣第一环）
关二狗走出去、门快关上的时候，李瞎子没帮他，也没笑他，只是把卦筒往怀里又拢了拢，对着空气说了半句：

> **李瞎子**：「……少走夜路哦。」

- 音量很轻，**关二狗没回头，玩家不一定听清**。
- 不弹提示，不进规矩本，不解释。
- **① .5 城墙根卦摊**：李瞎子会说出完整版「你身上带着点阴气，最近少走夜路。」——玩家第二次听见。
- **② 夜背崖墓尸**：应验。
- 游戏**永不确认**他是真半仙还是碰巧。

## 史实注

1. **茶馆里有算命先生** ✅ 成立。王笛《茶馆：成都的公共生活与微观世界》系列研究明确记载，民国成都茶馆"三教九流混杂"，**算命先生**与工匠、挑水夫、剃头匠同为茶馆常驻活跃人群；茶馆兼具信息交流、会社联谊、民间法庭、文化活动与经济交易功能。李瞎子在茶馆出现无需额外解释。
2. **称呼校准** ✅ 全场无人使用「师傅」作泛称。小二、脚夫对关二狗直呼或叫行当（「背死人的」），符合民国初年语感。
3. **香灰压尸臭** ⚠️ 未查到硬史料。作为杠房行业习惯写入，属民俗合理推演；若日后查证不成立，可改为"生石灰味""桐油味"等杠房实物气味，不影响节拍结构。
