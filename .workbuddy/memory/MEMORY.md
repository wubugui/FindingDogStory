# 项目长期记忆（FindingDogStory / 关二狗的故事）

## 人物动机铁律
- **关二狗**：上山背尸**就是为了钱，纯贪婪驱动**。不要加任何"恻隐、救赎、骑虎难下、自我感动"之类的东西。他是 con artist，从一开始就没打算真接活，是钱把他一步步套进去的。
- 他不知道自己的生辰八字（"阴司黑户"，可避超自然反噬）；对官府谎报属相"属狗"是随口编身份的日常，不是有预谋。

## 地名体系（主线开场，已基本敲定）
```
雾津城 → 城门口 → 郊野官道 → 跑马梁 → 牛头荡 → 崖墓分段
```
- **跑马梁** = 崖顶平梁/平路（不是悬崖本身）。
- **牛头荡** = 崖 + 半腰栈道 + 崖下水潭的**整体地理单元**，得名于崖壁探出的**牛头形巨石**。
- **崖墓分段**（牛头荡内部子场景）：入口 / 前段 / 前段1 / 后段 / 后段1 / 法坛。
- 癞子台词"牛头凼"指崖下那洼水（凼=水潭），与"牛头荡"（整体）可并存；最终用字待用户定。

## 阿秀线定稿要点（源：《阿秀支线-完整剧情与主线实施方案》修订三／四 · 第 4 档正典）

- **尸不离桃溪，动的只有那个帕子包**＝她的"自己"（铜亮纽子／半张洋烟盒纸／**空香粉盒**／几缕零线／一截带"倒回针·收尾多压半针"的活计）。
- **无魂无魄怎么缠人**：死时那口"不撒手"执念凝成**盲目念气**、凝在尸气里不散（＝尸不化之因，**不是**嫁衣没缝完）；**念气认物不认人**，物在哪就往哪够。全程无意识、非复仇、非守护、不会说话。
- **占有与保护同刀**：同一口念气，摁在死人身上＝锁住烂在原地（鬼村）；摁在揣物的活人身上＝收住不让灾祸夺走（护）。救与劫是同一个动作。
- **"不腐"切两种**：潭中尸须"绳石坠潭＋终年冰寒潭水"；地面横死该烂还烂。**唯她那一炸能在潭外批量锁住方圆一片。**
- **时间线＝浩劫"十年前"**（掌柜的 2026-09-10 口述，最高判据）。亨利取阳石 → 取阴石失败逃走 → 灾变期炸潭 → 阿秀成尸、桃溪成鬼村 → 帕子包辗转脏行当 → 如今克拉拉夫妇循记载来取阴石＝主线现在。**亨利与阿秀都属"主线十年前"，故二人在主线里只能以痕迹／传闻存在，不该有正面戏份。**
  - ⚠️ **口径冲突待修**：《阿秀支线-完整剧情与主线实施方案》红线速查写的是"时间线＝浩劫**几年前**（凡旧稿'十多年前'一律改'几年前'）"。按"用户当次审批＞文档"，应以**十年前**为准，该红线需修订。
- **阿秀在游戏里的存在形式**（掌柜的 09-10 明示）：**香粉味是实质性的接触**——一个死去的人与玩家／关二狗的实际互动，不是氛围符号；**她的其余一切，全部来自剧情传闻与线索搜集**。所以这条线不是"讲一个人"，是**让玩家查一个人**。
- **关二狗与桃溪是两条独立、且他浑然不觉的线**：①几年前烧"女妖"那阵他跟着人群看热闹、petty 起哄；②后来贪财辗转捡到帕子包、没舍得扔。**念气只认物不认人，救他跟"他起哄"毫无因果。严禁写成"他害过她→报应/被她缠"。**"教训女妖"＝事后吹牛注水，非真私仇。
- 她最终无魂无魄、没有恨、忘了一切；"旱魃"只是民间错叫，**故事不裁定她是旱魃**。
- **事实层坐实／裁定层悬置**：让玩家确信"发生了什么"，"这意味着什么"（对错／是不是旱魃／是不是复仇／她舍不得还是沾了煞）**永不闭环**。
- 山口扳机＝"**看见桃溪**"这一眼；不看就头也不回地跑。终章＝山口化身（给真选择、绝不 railroad、无剧情后果、怎么选都可以、游戏闭嘴）；"走＝／留＝"的阐释**严禁入游戏**。

## 记录纪律：掌柜的说「记录」＝只记原话（2026-09-14 血泪教训）

- 掌柜的说「记录一个想法／点子」时，**文件里只放他的原话**。归纳、解读、系统接口、风险分析、待定项——**一律不进文件**。
- 翻车现场：记「阴币买灯」点子时我自作主张加了「我的理解／系统接口／P0 冲突／6 条待定／5 条风险」，被当场骂回：**「原封不动记录我的想法，别瞎几把解读！」**
- 有想说的（比如发现设定冲突），**口头提一句就够**，不往文档里塞；掌柜的没接就不动。
