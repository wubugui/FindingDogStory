## 地名体系头脑风暴结论（基于 F:\未审核素材 11 张图）
图片是同一地理单元（牛头荡）的不同切面，色调统一：紫红/红褐崖壁、青绿水、枯松、雾山。

修正了之前的三个错：
1. "牛头荡"不是单一水潭，是**崖+半腰栈道+崖下水潭的整体地理单元**，得名于崖壁探出的**牛头形巨石**（地标）。
2. "跑马梁" = **崖顶平梁/平路**（图片证实），不是给悬崖命名，与悬崖是上下两个独立地名。
3. 悬崖边小道不需要另起名，栈道就在"牛头荡"内部。

最终地名体系（4 主体 + 1 子场景列表）：
```
雾津城 → 城门口 → 郊野官道 → 跑马梁 → 牛头荡 → 崖墓分段
                                              ├ 入口
                                              ├ 前段 / 前段1
                                              ├ 后段 / 后段1
                                              └ 法坛（崖墓2 / 崖墓2无灯 / 悬崖法坛）
```
